# On the Global and Local Calibration of Graph Neural Networks

This repository contains the official Notebook for the paper **"On the Global and Local Calibration of Graph Neural Networks"**, submitted to **Workshop: Towards Trustworthy Predictions: Theory and Applications of Calibration for Modern AI** at **AISTATS 2026**.

## Contents
* `main.ipynb`: Implementation of the proposed methods and experiments.
